# Seguridad

Los repos de esta comunidad son material de estudio: apps de ejemplo, ejercicios y scripts pequeños. Aun así, si encontrás algo que pueda poner en riesgo a quien los usa, queremos saberlo.

## Qué reportar

1. Una clave, token o contraseña que se haya subido por error.
2. Un workflow de GitHub Actions que pueda ejecutar código de un pull request ajeno o filtrar secretos.
3. Un script o una dependencia que haga algo distinto de lo que dice.
4. Un enlace que lleve a un sitio malicioso o a una copia falsa de un curso.

## Cómo reportar

No abras un issue público. Entrá a la pestaña **Security** del repo y usá **Report a vulnerability**. Contá qué encontraste, en qué archivo y cómo se reproduce.

Vas a recibir respuesta en unos días. Cuando esté corregido, te damos crédito en el arreglo si querés.
